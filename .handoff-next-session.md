- `git mv old new` moves `old` **into** `new/` if `new` already exists on disk as a directory (e.g. from an untracked datagen run) — it does not overwrite/merge in the way you might expect. If the destination might already exist, `mkdir -p` a placeholder isn't a fix; check `find new -maxdepth 1` first and merge by hand if both sides are populated.
