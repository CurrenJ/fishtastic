Recommended board

36-pixel baseline rows preserve the verb, count and essential condition. Ready is local to the current destination; the navigation counts expose other claimable rewards. The original warm mauve card backgrounds are retained. Green is reserved for readiness controls and indicators. Difficulty uses the original bronze, silver and gold panel sprites; focus has a separate outline.

Matched comparison

The same five quest identities, targets, rewards and progress appear on both sides, with zero tokens, zero ready rewards and the same reset time. This compares visual organization; it is not evidence of improved task completion time.
